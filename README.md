# Н2 Инжиниринг

Адаптивный многостраничный сайт по макету Figma. HTML, CSS, JavaScript без сборщика и внешних runtime-зависимостей. Все изображения загружены в `assets/`.

## Запуск

Откройте `index.html` в браузере или выполните:

```powershell
node server.mjs
```

Адрес: http://127.0.0.1:4173

## Возможности

- Адаптивные сетки и мобильное меню.
- Горизонтальная прокрутка преимуществ, стрелки и переключение двух флагманских кейсов.
- Отдельные страницы компании, проектов, прессы и карьеры, 7 проектов, 6 публикаций и 6 вакансий.
- Фильтры публикаций и просмотр фотографий проекта в диалоге.
- Отклик на вакансию открывает общую форму с темой вакансии и адресом HR.
- Форма с проверкой обязательных полей и согласием; подготавливает `mailto:` письмо. Для серверной отправки требуется подключить обработчик.
- Управление диалогами с клавиатуры, закрытие по Escape и клику за окном, поддержка reduced motion.
- `ui-kit.css` переносит состояния Default/Hover из Figma `4012:3833`: металлические текстуры, светлеющий основной градиент, переход светлых кнопок и стрелок в основной цвет, белые SVG-стрелки и тени. Длительность в UI kit не задана: для веба выбрано 220 мс ease-out. Размеры кнопок при переходе не меняются. Focus-visible повторяет Hover; на сенсорных устройствах обратная связь работает через Active. При reduced motion цвета переключаются без анимации.

## Контент перед публикацией

Результаты проверки мобильной версии, диапазон размеров и ограничения проверки описаны в `RESPONSIVE-QA.md`.
Сверка десктопа с координатами Figma и результаты проверки описаны в `DESKTOP-QA.md`; десктопные уточнения находятся в `desktop.css`.

Макет содержит демонстрационные реквизиты (ИНН, ОГРН, банковские данные). Необходимо заменить их достоверными. Полные тексты в макете есть для одной статьи и вакансии инженера-конструктора; остальные карточки открывают отдельные краткие страницы с возможностью запроса информации. Юридические документы остаются информационными окнами: утверждённые тексты не предоставлены. Английская версия не предоставлена, RU показывает текущий язык.

## Внутренние страницы

- `about.html` — о компании.
- `projects.html` — каталог проектов; `project-*.html` — страницы проектов.
- `press.html` — публикации с фильтрами; `article-*.html` — статьи.
- `careers.html` — шесть вакансий; `vacancy-*.html` — страницы вакансий.
- `pages.css`, `pages.js` — оформление и поведение внутренних страниц.

Шапка, подвал и контактные диалоги берутся из главной страницы генератором `build-pages.mjs`. После изменений общих блоков выполните `node build-pages.mjs`. Генератор использует `page-content.json` с текстами исходного макета.

Проверка файлов, ссылок и якорей: `node verify-pages.mjs`. Результаты браузерной проверки: `PAGES-QA.md` и `pages-audit.json`.

`design-reference.txt` и `design-screenshot.png` — справочные материалы для сверки, сайт их не использует. `download-assets.ps1` — скрипт первоначальной загрузки ассетов, временные ссылки Figma со временем истекают.
